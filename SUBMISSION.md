## Project Overview

Ajaia Docs is a lightweight document editor inspired by Google Docs. It allows users to create, edit, organize, import, and share documents with different access permissions.

## Implemented Features

- User registration and JWT authentication
- Document creation, editing, renaming, and deletion
- Rich-text editing with Tiptap
- Automatic saving
- TXT file import
- Document sharing with registered users
- Viewer and editor permissions
- PostgreSQL persistence
- Backend validation and error handling

## Technology Stack

- Express.js
- PostgreSQL
- Prisma ORM
