# AI Workflow — Ajaia Docs

## 1. Overview

AI tools were used as development assistants during the implementation of Ajaia Docs. They helped with planning, code suggestions, debugging, documentation, and understanding technical concepts.

## 2. AI-Assisted Development

AI assistance was used for:

- Planning the application architecture and development workflow.
- Generating and reviewing React components.
- Implementing Express API endpoints and Prisma database operations.
- Understanding JWT authentication and document-sharing permissions.
- Troubleshooting frontend and backend integration issues.
- Improving input validation and error handling.
- Preparing project documentation and test cases.

## 3. Human Review and Verification

AI-generated suggestions were reviewed and adapted before being used.

Verification included:

- Running the frontend and backend locally.
- Testing user registration and login.
- Creating, renaming, editing, and deleting documents.
- Checking document persistence.
- Testing document-sharing API endpoints.
- Running automated tests using Node.js built-in test runner.

## 4. Testing Results

The document validation utility was tested using five automated test cases.

All five tests passed successfully.

## 5. Responsible AI Usage

AI was used as a development assistant, not as a replacement for understanding or verification.

The final implementation was reviewed and tested locally. Technical decisions and code changes were evaluated against the assignment requirements.
